# file_finder_tui

極簡 Windows 檔名搜尋與資料夾瀏覽工具。使用 Python 3.11 以上與 Textual，執行時只有 Textual 一項直接第三方依賴。搜尋固定三個根目錄，不讀取搜尋檔案的內容。搜尋與瀏覽共用名稱索引，使用 Python 內建 SQLite 保存完整目錄快取，重啟後可還原並背景核對變動。收藏寫入設定檔旁的 `favorites.json`；索引快取保存在同資料夾的 `.file-finder-index.sqlite3`。

## 實作方式與範圍

程式分為兩個檔案，啟動指令維持 `python main.py`：

| 檔案 | 職責 |
| --- | --- |
| `main.py` | TUI 前端、啟動入口、鍵盤／滑鼠事件、瀏覽歷史及背景工作協調 |
| `backend.py` | 設定讀取、名稱搜尋、索引保存與增量核對、資料夾與收藏清單、最愛保存及檔案開啟；只依賴 Python 標準函式庫 |

沒有新增檔案預覽、複製、刪除、移動或重新命名功能。

介面預設使用低調霧藍主題：深黑背景、柔和藍色選取列與清楚的鍵盤焦點邊框。搜尋欄與清單使用黑灰底，首頁、搜尋、資料夾瀏覽和確認／錯誤對話框使用一致配色。字型與字級由 Windows Terminal 控制；顏色需終端支援真彩色才能完整呈現。

- 搜尋文字停止變更 250ms 後，使用 Textual 執行緒 Worker 查詢共用索引；未掃描的資料夾才使用 `os.scandir()` 讀取。完整掃過的資料夾保留全部項目名稱與修改時間，後續查詢、進入／返回資料夾及切換分頁可直接重用。
- 索引只保存完整且無讀取錯誤的資料夾；取消、達掃描上限或讀取失敗的半份資料不會當成完整索引。取消搜尋時，之前已完整掃完的其他資料夾仍保留。不同背景工作同時讀取同一資料夾時共用讀取結果。
- 完整掃描的目錄在背景以 SQLite 交易保存；每次只保存有變化的快取。啟動還原目前三個根目錄與收藏範圍內的快取，先提供名稱查詢，再背景逐一核對已索引目錄的修改時間、變更時間與檔案系統身分。深層目錄也各自核對，不能只看最上層根目錄。核對期間底部標示「背景核對」，發現變動後更新目前畫面。
- 搜尋期間約每 200ms 回報已掃描項目、目前找到至少幾筆、最近回報的掃描資料夾、讀取錯誤與排除連結數；底部持續更新耗時。輸入新條件或返回首頁後，舊進度不能覆蓋畫面。
- 文字一改變，立即設定上一個取消旗標並更新請求序號；只有最新序號可更新畫面。清除、返回與退出也會使舊結果失效。
- 比對名稱時使用 `casefold()`，空白分隔的所有關鍵字都必須完整出現在名稱中，不要求關鍵字順序。例如 `契變 2026` 可命中 `2026_契變報告.xlsx`，但不會命中 `契變報告.xlsx`；`rpt` 不再命中 `report.xlsx`。不讀取檔案內容，也不比對父目錄路徑。
- 排序依序為資料夾、整段連續命中、名稱長度、名稱。相同名稱以完整路徑穩定排序；資料夾必定排在檔案前面，也適用於搜尋結果的 200 筆保留上限。
- 清單每個項目顯示檔案系統的最後修改時間（`YYYY-MM-DD HH:MM:SS`），使用執行電腦的本地時區；無法讀取時顯示「無法取得」。項目之間保留一行留白。進入資料夾後，完整路徑只顯示在上方，子項目只顯示名稱與更新時間；跨目錄搜尋仍顯示父目錄路徑以區分同名檔。
- 「資料夾」與「我的最愛」使用獨立分頁，各自保留查詢文字、選取位置及瀏覽歷史。資料夾分頁搜尋固定三個根目錄；最愛分頁只篩選已收藏的檔案／資料夾名稱，不遞迴搜尋收藏資料夾內未收藏的項目。切換分頁立即使舊搜尋失效。
- 清單或分頁取得焦點時，直接打字或貼上便會聚焦搜尋欄並輸入內容；第一個字不會遺失。收藏使用 `Ctrl+F`，因此 `f` 可以正常輸入。確認／錯誤對話框維持自己的輸入操作。
- 最多保留排序最佳的 200 筆搜尋結果，但在掃描完成後顯示實際命中總數，並非找到 200 筆就停止。
- 達上限、取消或出現讀取錯誤時，標示「結果不完整」與「已找到至少 N 筆」。所有錯誤保留在本次記憶體報告中，底部顯示錯誤數量與第一項資訊；按 `Ctrl+E` 可捲動查看目前畫面的全部讀取錯誤。
- 資料夾只列出直接子項目，不遞迴展開；瀏覽清單及索引不套用 200 筆搜尋結果上限。清單只為可見或實際選取的項目建立顯示內容，顯示快取最多 128 筆；仍可用方向鍵、PageUp／PageDown、Home／End 走訪全部內容。列高固定，超過寬度的文字以省略號顯示；滑鼠停留在項目上可查看完整名稱。200 筆仍只限制搜尋結果，換關鍵字可搜尋其他已索引項目。
- `F5` 為增量更新：瀏覽畫面只核對目前資料夾，搜尋／首頁核對所有已載入的目錄；只重新枚舉時間或身分有變動的目錄。搜尋／瀏覽更新也重新讀取既有項目的修改時間，不必為單純檔案修改時間變動重新枚舉整個資料夾。未變動目錄保持快取。
- `Ctrl+F5` 清除保存的索引紀錄與記憶體快取，再依目前畫面重新讀取；首頁只更新根目錄資訊，之後搜尋或進入資料夾時才重建其索引。這個操作只改動本程式的快取，不刪除搜尋檔案。舊背景工作不能寫回已失效的記憶體索引；同一實例的保存與清除在資料庫鎖下依序完成。
- 滑鼠單擊只選取項目；雙擊或 Enter 才開啟檔案／進入資料夾。執行類型仍會要求確認。清單有焦點時按 `Ctrl+O` 可用 Windows 開啟選取項目的父資料夾，不會啟動選取的檔案。
- 最愛以同目錄暫存檔、`flush`、`fsync`、`os.replace` 原子保存；寫入失敗時保留原 JSON 與記憶體收藏。
- 名稱、路徑與錯誤中的終端控制碼及 Unicode 方向控制字元以 `\\xNN`／`\\uNNNN` 顯示，不改動實際檔案路徑。設定與收藏 JSON 的讀取／收藏保存上限為 2 MiB；無效路徑、過深 JSON 或超限資料提供提示，收藏寫入失敗不覆蓋舊檔。

## 已知限制與風險

- 第一次遇到資料夾、偵測到目錄變動或完整重建後需要掃描；大型目錄／慢速網路首次讀取可能較久。後續查詢仍須比對記憶體中的名稱。預設每次搜尋最多檢查 250,000 個子項目，包含快取項目，達上限會明確標示不完整。三個設定根目錄本身也參與名稱比對。
- 啟動背景核對只檢查目錄，不逐一查詢所有檔案；尚未核對完的結果可能是上次快取。單純修改檔案內容可能不改變父資料夾時間，因此修改時間以 `F5` 重新核對為準。沒有持續檔案系統監看；執行期間新增／刪除／改名後請按 F5。時間戳記不可靠或被還原的檔案系統，請用 Ctrl+F5 完整重建。
- 索引快取只包含路徑、檔名、類型與修改時間，仍屬個人資料，已排除 Git 追蹤。快取損壞、版本不符或無法寫入時保留該檔，介面提示改用記憶體索引，搜尋仍可使用；請先備份再手動處理異常快取。若快取所在資料夾也在搜尋範圍，SQLite 保存可能讓該資料夾再次被判定變動。
- 每份目錄快取最多保存／讀取 64 MiB，啟動最多還原 1,000,000 個項目；超限整份目錄跳過，之後需要時重新讀取，不使用半份快取。這些是保存／還原限制，不是資料夾瀏覽的筆數上限。記憶體用量與首次清單排序仍取決於實際項目數量。
- 搜尋前不知道全部項目數量，因此進度不顯示百分比或預估剩餘時間；掃描上限不是檔案總數。搜尋中顯示的筆數標示「尚未完成」，結束後才套用完整／不完整結果的說明。短時間完成的搜尋可能直接顯示最終結果。
- 為避免跨出掃描範圍與循環，搜尋與瀏覽都排除符號連結及 Windows reparse point，包含 junction、部分雲端佔位檔。狀態會顯示排除數量；「完整」指依此排除規則完成的掃描。
- 直接指定的根目錄、收藏、資料夾瀏覽及檔案開啟也檢查目標的符號連結／reparse 屬性。這是操作前檢查，不是檔案系統安全沙箱；父路徑上的連結與檢查後被其他程式替換的競態仍無法完整阻止。請避免以較高權限處理不可信的可寫資料夾。
- Windows 路徑比較不分大小寫，並正規化 `.`、`..`、尾端斜線與分隔符；不同磁碟映射／UNC 別名並不會自動合併。此工具不適用刻意啟用大小寫敏感的特殊目錄。
- Python 無法強制中斷正在等待 Windows 回應的單次檔案系統呼叫。UI 可以繼續操作，舊結果會被丟棄；若網路磁碟呼叫卡住，背景執行緒及程式結束可能仍需等待 Windows 逾時。
- 等待檔案系統回應時，耗時仍會增加，但項目計數及最近回報的資料夾可能暫時停住；這不代表該目錄已完成掃描。讀取錯誤的完整清單在本次搜尋結束後可用 `Ctrl+E` 查看。
- 清單採可見列繪製，減少大量 Option 建立與排版；背景首次讀取、排序及大份快取載入仍需要時間，並非所有檔案系統操作都有固定耗時。
- 執行檔、腳本、安裝程式及捷徑會要求確認，預設焦點在「取消」。常見確認副檔名包含 `.exe`、`.bat`、`.cmd`、`.ps1`、`.vbs`、`.js`、`.msi`、`.reg`、`.lnk`、`.url`、`.py` 等。副檔名清單不是完整的程式安全沙箱。
- 一般檔案透過 Windows 預設關聯程式開啟；後續外部程式的行為由該程式負責。自動測試使用開啟函式替身，沒有執行真實腳本或啟動真實關聯程式。
- `favorites.json` 損壞／無法讀取時會停用收藏寫入，避免覆蓋舊資料；修正檔案後請重啟。不支援同時執行多個實例修改收藏，以免最後一次保存覆蓋其他實例的變更。
- 映射磁碟必須在目前使用者的 PowerShell 工作階段已連線。不要求管理員權限；實際 ACL 拒絕與網路斷線以可重現的例外注入測試驗證，尚未實際斷開使用者的網路磁碟。

## 安裝與設定

前置條件：Windows 10／11、PowerShell、Python 3.11 以上；建議使用 Windows Terminal。無需 Docker、管理員權限或啟用 PowerShell 執行腳本權限。

從 GitHub 下載專案後，在專案目錄建立虛擬環境並安裝 Textual：

```powershell
Set-Location 'C:\path\to\file-finder-tui'
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path .\config.json)) {
    Copy-Item .\config.example.json .\config.json
}
notepad .\config.json
```

如果 `py -3.11` 無法執行，請將 `py -3.11` 換成已安裝的 Python 3.11+ 執行檔完整路徑。直接呼叫虛擬環境中的 Python 即可，無需啟用 `Activate.ps1`。

Git 僅追蹤設定範本 `config.example.json`。實際使用的 `config.json` 與個人收藏 `favorites.json` 已加入 `.gitignore`，本次遷移保留本機原有內容並取消 Git 追蹤。首次執行請以上述指令建立設定；缺少設定時程式會顯示建立提示。首次收藏時會建立 `favorites.json`。

輸入設定預設為程式旁的 `config.json`，首頁會顯示實際讀取的設定檔完整路徑。`roots` 必須剛好三筆，且 `path` 必須為絕對路徑。JSON 中反斜線需寫成 `\\`：

```json
{
  "roots": [
    {"name": "Project A", "path": "C:\\Projects\\Alpha"},
    {"name": "Project B", "path": "C:\\Projects\\Beta"},
    {"name": "Project C", "path": "U:\\SQL"}
  ],
  "max_scan_entries": 250000
}
```

範例中的路徑是示範值。執行前請改為你要搜尋的三個實際資料夾；例如可以使用 `U:\SQL` 或 UNC 路徑。無效路徑在首頁顯示「失效／無法讀取」，其餘根目錄仍可搜尋；設定格式錯誤會顯示提示並停用搜尋，修正後重啟。

最愛保存為絕對路徑的 JSON 陣列：

```json
[
  "U:\\SQL",
  "D:\\Shared",
  "D:\\Shared\\report.xlsx"
]
```

最愛可以收藏單一檔案或資料夾，也可以指向三個根目錄以外的路徑供直接開啟／瀏覽，但不會擴充資料夾分頁的搜尋範圍。JSON 仍使用絕對路徑陣列，既有收藏可以直接沿用。失效收藏保留紀錄，可在我的最愛分頁選取後按 `Ctrl+F` 明確移除。

## 執行與快捷鍵

```powershell
Set-Location 'C:\path\to\file-finder-tui'
.\.venv\Scripts\python.exe .\main.py
```

啟動時位於資料夾分頁，搜尋欄位為空時只顯示三個根目錄，根目錄項目會顯示完整設定路徑。我的最愛分頁獨立顯示收藏的資料夾與單一檔案；空清單會提示如何收藏。所有清單都顯示更新時間，已收藏的項目顯示 `★`。資料夾內的路徑只顯示在上方；跨目錄搜尋結果保留父目錄路徑，以區分同名項目。

| 操作 | 行為 |
| --- | --- |
| `↑`／`↓` | 移動清單選取；搜尋欄位或分頁取得焦點時，切換到清單首／末項。點選我的最愛後可直接按 `↓` 進入清單 |
| `Tab`／`Shift+Tab` | 切換分頁、搜尋欄位與清單焦點 |
| 直接打字／貼上 | 清單或分頁有焦點時，自動聚焦搜尋欄並輸入；`f` 為正常搜尋文字 |
| `Enter` | 清單中開啟檔案或進入資料夾 |
| `Ctrl+F` | 清單取得焦點時加入／取消檔案或資料夾最愛 |
| `Alt+1`／`Alt+2` | 切換資料夾／我的最愛分頁 |
| `Ctrl+Tab` | 切換至另一個分頁；也可用滑鼠點擊分頁 |
| `Ctrl+L` | 聚焦搜尋欄位 |
| `F5` | 增量核對；瀏覽只核對目前資料夾，搜尋／首頁核對已載入的所有目錄。未變動的目錄保持快取 |
| `Ctrl+F5` | 清除本程式索引並依目前畫面重建；對話框內不操作主畫面 |
| `Ctrl+O` | 清單有焦點時用 Windows 開啟選取項目的父資料夾 |
| `Home`／`End`／`PageUp`／`PageDown` | 清單首尾／換頁移動，全部資料夾子項目皆可走訪 |
| `Backspace` | 清單中返回前一個瀏覽畫面；輸入欄位中正常刪字 |
| `Alt+←`／`Alt+→` | 搜尋欄位或清單取得焦點時返回／前進；對話框內不切換瀏覽歷史 |
| `Ctrl+E` | 查看目前畫面的全部讀取錯誤；清單可用方向鍵或 PageUp／PageDown 捲動 |
| `Esc` | 返回前一個瀏覽層級，保留原搜尋與選取；搜尋清單沒有上一層時返回目前分頁首頁。確認／錯誤對話框只關閉目前對話框 |
| 連按兩次 `Esc` | 0.5 秒內連按兩次，直接返回目前分頁首頁，清除查詢與瀏覽歷史；中間有其他按鍵、滑鼠點擊或貼上則不算連按 |
| `Ctrl+Q` | 結束程式 |
| 滑鼠單擊 | 只選取項目，不開啟 |
| 滑鼠雙擊 | 開啟檔案或進入資料夾；執行類型仍需確認 |

從搜尋結果或最愛直接進入深層資料夾，第一次返回會回到原搜尋結果或首頁，並保留選取位置。只有實際進入過的資料夾才形成返回歷史，不會直接跳到未瀏覽過的父目錄。`Esc` 單次返回一個歷史層級，例如首頁 → A → B → C，在 C 按一次會回到 B；間隔超過 0.5 秒再按一次會回到 A；快速連按兩次才直接回目前分頁首頁。`Alt+←`／`Alt+→` 可在已走過的瀏覽、搜尋與首頁畫面之間前後切換；新的搜尋、回首頁或進入其他資料夾會清除可前進歷史，單次 Esc 返回則保留前進歷史。返回或前進至資料夾時重用已完整掃過的快取；原搜尋結果則還原到進入前的畫面。

## 驗證

只檢查設定與三個根目錄是否可讀，不遞迴搜尋或修改收藏：

```powershell
Set-Location 'C:\path\to\file-finder-tui'
.\.venv\Scripts\python.exe .\main.py --check
$LASTEXITCODE
```

全部根目錄可讀時退出碼為 `0`；設定或任一根目錄有問題時為 `1`。檢查網路路徑仍需等待 Windows 的檔案系統回應。

指定其他設定檔時，最愛預設保存於該設定檔旁：

```powershell
.\.venv\Scripts\python.exe .\main.py --config 'C:\Example\config.json'
```

pytest 僅供測試，不是程式執行依賴：

```powershell
Set-Location 'C:\path\to\file-finder-tui'
.\.venv\Scripts\python.exe -m pip install pytest
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q main.py backend.py tests
```

測試以 pytest 的 `tmp_path`／`tempfile` 建立三個根目錄與多層假資料，測試名稱搜尋、同名路徑、排序與 200 筆限制、掃描上限、取消與過期結果、歷史、即時子項目、收藏重載／原子寫入失敗、無效設定、權限與網路例外，以及 Textual 鍵盤／滑鼠操作和執行確認。Windows junction 測試只在暫存資料夾建立迴圈，不需符號連結管理員權限。

本次驗證以實際 `os.scandir()` 呼叫計數確認換查詢、瀏覽與返回共用索引；另涵蓋超過 200 筆的完整索引、取消／錯誤／上限時不保存半份資料、只更新指定資料夾、並行讀取共用結果，以及更新後舊工作不寫回過期快取。介面測試涵蓋資料夾路徑只顯示在上方，跨目錄搜尋仍保留路徑，以及返回快取後用 F5 取得新增檔案。原有搜尋、收藏、分頁、Esc、鍵盤及錯誤處理測試保留。測試只建立暫存假資料；Windows junction 測試在其他作業系統會略過。

索引保存測試涵蓋重新建立 DirectoryIndex 後還原 230 筆完整子項目、只重讀變動的深層目錄、既有檔案修改時間更新、已刪目錄、異常資料庫保留、異常子路徑拒絕、取消時不保存半份資料、範圍隔離、還原上限與重建／保存並行。UI 測試以 20,001 筆項目驗證只格式化少量可見項目、首尾與換頁／Enter 操作、單擊不開啟、雙擊確認、Ctrl+O 開啟父資料夾，以及啟動背景核對後目前搜尋自動更新。

本次全套驗證為 129 通過、1 略過（Windows junction），編譯檢查及 Bandit 通過。本機 Linux／Python 3.12.14 的 20,001 筆清單單次視圖更新比較：原版 `render_view()` 約 1.39 秒，新版約 0.001 秒；首次可見畫面建立 8 個 Option，原版建立 20,001 個。這只量測清單視圖建立，不包含搜尋、排序、快取讀寫或 Windows 實際顯示耗時。另核對 110×40 與 80×24 視窗，仍可顯示清單及主要操作提示。

2026-10-01 的弱點掃描、相依套件版本、可重現風險、修正與剩餘限制見 [security-review.md](security-review.md)。安全回歸測試位於 `tests/test_security.py`；套件掃描工具只供開發使用，未加入程式執行依賴。
